**03_Code Folder**

This folder contains the core modeling code used to simulate two key circular interventions:

    d.3 Uruguay's Plastics Recycling (refer to the Excel file LATAM:data_entry_final for intervention data). See the main script Main Code MRIO Uruguay for details.

    b.1 Costa Rica's Increase of Biodegradable Waste from Food (refer to the Excel file LATAM:data_entry_final for intervention data). See the main script Main Code MRIO Costa Rica for details.

The code implements MR-EEIOA methodology leveraging the EXIOBASE database to quantify environmental and socio-economic impacts. It estimates changes in greenhouse gas emissions, nutrient cycles, land use, value added, and employment resulting from the specified circular economy strategies.
