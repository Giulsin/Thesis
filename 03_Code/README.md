**03_Code Folder**

This folder contains the core code used to model two key circular interventions:

    d.3 Uruguay's Plastics Recycling (See excel file LATAM:data_entry_final)

    b.1 Costa Rica's Increase of Biodegradable Waste from Food (See excel file LATAM:data_entry_final)

The code simulates the impacts of these interventions on multiple environmental and socio-economic indicators, including greenhouse gas emissions, nutrient cycles, land use change, value added, and employment.

These models utilize the EXIOBASE database and the MR-EEIOA framework to quantify the effects of circular economy strategies at a regional and global scale, providing essential insights for understanding and advancing sustainable development in Latin America.
