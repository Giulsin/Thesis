**Modelling Info Folder**

This folder contains essential support materials for modeling circular economy interventions using EXIOBASE. It provides detailed instructions for aggregating sectors and regions, enabling the assessment of intervention impacts across key global areas including Latin America, the European Union, China, the United States, and the Rest of the World (RoW).

Sector aggregation reorganizes the original dataset’s sectors to form meaningful groupings, which allows for focused analysis of changes in macro-sectors pertinent to circular economy strategies. This structured approach facilitates comprehensive tracking and evaluation of the circular interventions’ socio-economic and environmental effects.
